Политика конфиденциальности

Эта страница объясняет, какие данные могут обрабатываться при посещении сайта и обращении через Email, Telegram или WhatsApp.

1. Оператор данных

Оператор: Денис Черных. Для вопросов по обработке персональных данных можно написать на email: chernykh.d.o@yandex.com.

2. Какие данные обрабатываются

  • технические данные посещения сайта, которые может обрабатывать GitHub Pages для работы и защиты сервиса: IP-адрес, дата и время запроса, user agent, запрошенная страница;
  • данные, которые вы сами отправляете при обращении: имя или ник, email, номер телефона, аккаунт в мессенджере, содержание сообщения и приложенные материалы;
  • данные переписки в Email, Telegram или WhatsApp после перехода по внешним ссылкам с сайта.

3. Цели обработки

  • ответ на обращение и обсуждение проекта;
  • подготовка предложения, оценка задачи и дальнейшее взаимодействие по проекту;
  • обеспечение доступности, безопасности и корректной работы сайта.

4. Правовые основания

Данные обрабатываются на основании вашего обращения, необходимости ответить на запрос и подготовить возможный договор, а также законного интереса в поддержании безопасности сайта. Если отдельное действие требует согласия, оно запрашивается отдельно.

5. Сторонние сервисы

Сайт размещен на GitHub Pages. При переходе в Telegram, WhatsApp или при отправке email данные обрабатываются соответствующими сервисами по их правилам. Шрифты и иконки подключены локально, внешние Google Fonts и CDN для иконок на сайте не используются.

6. Cookies и аналитика

На сайте не используются cookies, рекламные пиксели, формы сбора заявок и встроенная аналитика. Браузерное localStorage может использоваться только для сохранения выбранного языка интерфейса.

7. Срок хранения

Переписка и материалы по обращению хранятся столько, сколько нужно для ответа, обсуждения проекта, исполнения договоренностей и защиты законных интересов. По запросу данные могут быть удалены, если нет обязанности или разумной необходимости хранить их дольше.

8. Ваши права

Вы можете запросить доступ к своим данным, уточнение, удаление, ограничение обработки или отзыв согласия, если обработка основана на согласии. Для этого напишите на chernykh.d.o@yandex.com.

9. Обновления

Политика может обновляться при изменении сайта, контактных каналов, сервисов или правовых требований. Актуальная версия опубликована на этой странице. Дата обновления: 03.06.2026.
