# Портфолио — разработка и автоматизация

Многоязычный сайт-портфолио для представления веб-разработки, автоматизации и работы с AI-инструментами.

## Возможности

- Русская, английская и немецкая версии.
- Презентация услуг, кейсов и способов связи.
- Локальные шрифты, иконки и автоматическая проверка ключевого контента.

## Инженерные акценты

- Упаковка технического опыта в понятные заказчику услуги.
- Интернационализация и согласованность контента.
- Самодостаточная статическая реализация с небольшим набором зависимостей.

## Стек

JavaScript, HTML, CSS.

## Разработка

```sh
pnpm install
pnpm dev
pnpm check
```
