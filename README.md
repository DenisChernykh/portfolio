# Frontend / AI / Automation Portfolio

Одностраничный сайт-визитка на русском языке для продажи услуг frontend-разработки, автоматизации и AI-усиленного решения задач для малого бизнеса.

## Что внутри

- `index.html` — готовый лендинг с HTML/CSS в одном файле.
- `privacy.html` — политика конфиденциальности для текущей версии сайта.
- `assets/i18n.js` — словари RU/EN/DE, переключение языка и клиентский автодетект для GitHub Pages.
- `assets/fonts/` — локально подключенные Manrope и Unbounded, плюс лицензии OFL.
- `assets/vendor/lucide.min.js` — локальная копия Lucide icons, чтобы сайт не обращался к CDN.
- `package.json` — команды для локального запуска через Vite.
- `scripts/check-content.mjs` — быстрая проверка, что ключевые блоки, кейсы и Telegram CTA не потерялись.

## Запуск

```bash
npm run dev
```

После запуска сайт будет доступен по адресу `http://127.0.0.1:5173/`.

## Проверка

```bash
npm run check
```

## Языки

Сайт поддерживает русский, английский и немецкий. Переключатель сохраняет выбор в `localStorage` и добавляет `?lang=ru`, `?lang=en` или `?lang=de` к внутренним ссылкам. При первом заходе язык выбирается по `?lang=`, затем по сохраненному выбору, затем по языку браузера; если совпадений нет, открывается русская версия.

## Перед публикацией

Проверь Telegram-ссылку в `index.html`: сейчас используется `https://t.me/ChDenis`.

На сайте есть дисклеймер, что информация не является публичной офертой. Отдельная оферта понадобится, если появятся фиксированные цены, онлайн-оплата, оформление заказа или автоматическое заключение договора через сайт.

Для немецкой версии подготовь данные для `Impressum` и политики конфиденциальности:

- полное имя или юридическое лицо;
- адрес для Impressum;
- email для быстрой электронной связи;
- статус: физлицо, ИП/самозанятый или компания;
- VAT ID / регистрационные данные, если есть.
